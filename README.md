# E2IT2_Tierheim_kimgoeb_sanvand
Repository für das Webentwicklung Projekt.

## Inhalt unserer Website
Unsere Idee ist eine fiktive Tierheim-Website, auf der Tiere vorgestellt werden und Interessenten über ein Formular Kontakt aufnehmen können.
Außerdem soll sie auch viele Informationen zu Tierhaltung enthalten und über Rassetiere/Qualzuchten informieren.

## Seiten und Funktionen
- "Startseite" (index.html) Vorstellung des Tierheims mit ersten Bildern
- "Unsere Tiere" mit Bildern der Tiere und einer Liste/Tabelle der wichtigen Daten
- "Interessiert" mit einem Formular zur Kontaktaufnahme
- "Welches Tier passt zu mir?" mit einem interaktiven Matching-System
- "Tierschutz und Qualzucht" mit wichtigen Informationen (vielleicht noch ein Formular zum Mitglied werden?)

## Geplante Features
- Grundstruktur Hauptseite
- Erste Tiere anlegen
- Ideen für die Gestaltung Sammeln
