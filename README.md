# E2IT2_Tierheim_kimgoeb_sanvand
Repository für das Webentwicklung Projekt.

## Inhalt unserer Website
Unsere Idee ist eine fiktive Tierheim-Website, auf der Tiere vorgestellt werden und Interessenten über ein Formular Kontakt aufnehmen können.
Außerdem soll sie auch viele Informationen zu Tierhaltung enthalten und über Rassetiere/Qualzuchten informieren.

## Seiten und Funktionen
- "Startseite" (index.html) Vorstellung des Tierheims mit ersten Bildern
- "Unsere Tiere" mit Bildern der Tiere und einer Liste/Tabelle der wichtigen Daten
- "Interessiert" mit einem Formular zur Kontaktaufnahme
- "Welches Tier passt zu mir?" mit einem interaktiven Matching-System
- "Tierschutz und Qualzucht" mit wichtigen Informationen (vielleicht noch ein Formular zum Mitglied werden?)

## Geplante Features
- Grundstruktur Hauptseite
- Erste Tiere anlegen
- Ideen für die Gestaltung Sammeln

Funktionieren tut er wie folgt: 
Man gibt auf einer .html seite das Wort "Button" ein und drüclt Enter. Daraufhin erscheint: 

<button></button>

Zwischen dem ersten n von "Button" und >, muss nun ein type gewählt werden. Es gibt 3 möglichkeiten die nun gewählt werden können:

button - keine vordefinierte funktion, reine Klickfläche
reset - setzt alle Felder der Seite wieder auf den Startwert
submit - sendet die eingegebenen Daten an eine selbstwählbare Zieladresse
-> da wir "submit" sicherlich für unser Kontaktformular verwenden werden erkläre ich das nun mal noch nicht ausführlicher.

Nun haben wir z.B.:

<button type="button"></button>

Jetzt können wir noch eine Beschriftung auf unseren Button packen. Dafür schreiben wir den ausgewählten Text zwischen das > nach "button" und vor das < vor dem /. 

Z.B.:

<button type="button">Kontaktformular</button>

Fertig ist der Button der "noch" nichts macht.
